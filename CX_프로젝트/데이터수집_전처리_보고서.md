## 1. 프로젝트 개요

### 1.1 기획 배경

신혼부부는 독립적인 주거 공간을 마련하면서 처음으로 주방가전을 직접 선택·구매하는 주요 소비자 집단이다.
특히 광파오븐은 전자레인지·오븐·에어프라이어 기능을 통합한 복합 가전으로, 요리 경험이 부족한 신혼부부에게 높은 잠재 수요가 있음에도 제품 이해도와 활용 콘텐츠가 부족한 상황이다.
이에 신혼부부의 실제 니즈와 페인포인트를 데이터 기반으로 파악하여, 광파오븐 관련 새로운 콘텐츠 서비스를 기획하고자 본 분석을 수행하였다.

### 1.2 분석 목적

| 구분 | 세부 목적 |
|------|-----------|
| 니즈 파악 | 신혼부부가 광파오븐에 대해 실제로 원하는 것 파악 |
| 페인포인트 발굴 | 현재 콘텐츠·제품에서 해소되지 않는 불만 요소 도출 |
| 기회 영역 도출 | Opportunity Score 기반 콘텐츠 우선순위 결정 |
| 콘텐츠 방향 제안 | 분석 결과를 바탕으로 신규 콘텐츠 서비스 방향 제언 |

### 1.3 분석 흐름

```
데이터 수집 (YouTube API)
        ↓
데이터 전처리 (정제 · 형태소 분석)
        ↓
LDA 토픽모델링
        ↓
감성분석 (감성사전 기반)
        ↓
Opportunity Score & Area 도출
        ↓
콘텐츠 서비스 기획 방향 제안
```

## 3. 데이터 전처리

### 3.1 전처리 목적

수집된 댓글 원문은 이모지, URL, 특수문자, 문법에 맞지 않는 구어체 표현 등이 혼재되어 있어
텍스트 분석 이전에 노이즈를 제거하고 의미 있는 단위(명사)로 가공하는 전처리 과정이 필요하다.

### 3.2 전처리 단계

#### Step 1. 텍스트 정제

- URL 제거: `http://`, `https://` 포함 URL 전체 삭제
- 특수문자 제거: 한글·영문·숫자·공백을 제외한 모든 문자 제거 (이모지, 특수기호 포함)
- 공백 정규화: 연속 공백을 단일 공백으로 통일
- 최소 길이 필터: 정제 후 5자 미만 댓글 제외

```python
def clean_text(text):
    text = re.sub(r"http\S+", "", text)
    text = re.sub(r"[^가-힣a-zA-Z0-9\s]", " ", text)
    text = re.sub(r"\s+", " ", text).strip()
    return text
```

#### Step 2. 형태소 분석 및 명사 추출

- 사용 라이브러리: **KoNLPy Okt** (Open Korean Text)
- 분석 단위: 명사(Noun) 추출
- 최소 길이: 2글자 이상 명사만 추출 (조사·어미·단음절 제거)
- 추출 근거: LDA 토픽모델링과 감성분석에서 문맥을 결정하는 핵심 품사가 명사이므로, 명사만 사용하여 분석 품질 향상

```python
from konlpy.tag import Okt
okt = Okt()
nouns = okt.nouns(text)
filtered = [n for n in nouns if len(n) >= 2 and n not in STOPWORDS]
```

#### Step 3. 불용어 처리

분석에 의미 없는 고빈도 단어를 불용어 사전으로 정의하고 제거하였다.
총 80개+ 불용어를 아래 6개 카테고리로 구성하였다.

| 카테고리 | 예시 |
|----------|------|
| 일반 조사·어미 | 이, 그, 저, 것, 수, 때, 등 |
| 고빈도 무의미 동사·형용사 | 하다, 되다, 않다, 없다 |
| 인터넷/유튜브 맥락 단어 | 유튜브, 영상, 댓글, 구독, 채널 |
| 구매 맥락 일반 단어 | 구매, 배송, 구입, 가격, 제품 |
| 시간 표현 | 오늘, 어제, 최근, 항상, 처음 |
| 이모티콘 텍스트 | ㅋㅋ, ㅎㅎ, ㅠㅠ, ㅜㅜ |

#### Step 4. 최소 토큰 필터

형태소 분석 후 명사가 2개 미만인 댓글은 분석에 활용하기 어렵다고 판단하여 제외하였다.

## 4. 분석 방법

### 4.1 LDA 토픽모델링

- 라이브러리: `gensim LdaModel`
- 토픽 수: 7개
- 학습 파라미터: passes=15, alpha="auto", eta="auto", random_state=42
- 사전 필터링: 5개 미만 문서에 등장하거나 60% 이상 문서에 등장하는 단어 제거
- 각 댓글에 확률 최대 토픽을 할당하여 주제를 분류

### 4.2 감성분석 (감성사전 기반)

도메인(신혼살림·주방가전·요리)에 특화된 한국어 감성사전을 자체 구성하였다.

| 구분 | 단어 수 | 예시 |
|------|---------|------|
| 긍정어 | 55개+ | 최고, 편리, 만족, 간편, 바삭, 필수, 강추, 꿀템 |
| 부정어 | 40개+ | 불편, 후회, 고장, 냄새, 청소, 단점, 비추, 실망 |

- 분류 기준: 댓글 토큰 내 긍정어 수 > 부정어 수 → 긍정 / 반대 → 부정 / 동수 → 중립

### 4.3 Opportunity Score (Ulwick, 2003)

Jobs-to-be-Done 방법론의 기회 점수 공식을 데이터 기반으로 재해석하여 적용하였다.

**공식**: `Opportunity Score = Importance + max(Importance − Satisfaction, 0)`

| 지표 | 산출 방법 |
|------|-----------|
| 중요도 (Importance) | 댓글 볼륨 비중(70%) + 평균 조회수(30%) → Min-Max 정규화 (1~10) |
| 만족도 (Satisfaction) | 긍정 댓글 / (긍정 + 부정 댓글) × 10 |

- 점수가 높을수록 → 사용자 관심은 높으나 현재 콘텐츠로 충족되지 않는 기회 영역

**Area 분류 기준 (2×2 Matrix)**

| Area | 중요도 | 만족도 | 전략 방향 |
|------|--------|--------|-----------|
| 과소충족 기회 | 높음 | 낮음 | 최우선 콘텐츠 개발 대상 |
| 충족 영역 | 높음 | 높음 | 기존 콘텐츠 유지·강화 |
| 과잉충족 영역 | 낮음 | 높음 | 신규 투자 축소 |
| 무관심 영역 | 낮음 | 낮음 | 후순위 |
